Sustituye la descarga de fichas completas y la agrupación de toda la cartera en Leaflet
por consultas de la zona visible y agrupación acotada en Rust. La cuadrícula sigue
Web Mercator y adapta su tamaño para acotar la respuesta incluso con peticiones extremas.

La consulta anterior repetía COUNT, ORDER BY, OFFSET y enriquecimiento de fichas en cada
página de 200 hasta 25.000 resultados. La nueva lee únicamente seis columnas en una pasada.

Pruebas: `cargo test --workspace`, `npm run build`, comprobación del contrato generado
y `node scripts/probar-mapa.mjs` sobre una base temporal independiente.

Verificado: 44 tests Rust pasan. El navegador pasa a 1440 px y 390 px, incluidos
zoom, filtros, paginación, apertura de ficha y parada de peticiones al salir del mapa.
La API con 55.000 empresas devuelve 400 elementos / 76.636 bytes en unos 53 ms
en release; la UI inicial dibuja 100 agrupaciones en escritorio y 36 en móvil.

Instalado en el servicio radar. Contrato y UI servidos coinciden con el build nuevo;
el índice geográfico está activo y se conservan las 55.604 empresas y los jobs pendientes.
